# Bitácora de Aprendizaje - Algoritmia

**Fecha:** 22 de octubre de 2026  
**Tema central:** Algoritmia  
**Actividad realizada:** Desarrollo de cinco proyectos en PSeInt con sus respectivos diagramas de flujo.


## 1. Objetivo de la Sesión
Aprender a organizar pasos para resolver problemas mediante algoritmos y representarlos con diagramas de flujo.

## 2. Actividades Realizadas

| Proyecto | Descripción |
| **Proyecto 1: Promedio de notas** | Cálculo del promedio de varias notas mediante operaciones matemáticas. |
| **Proyecto 2: Saludo** | Creación de un programa que muestra un saludo al usuario. |
| **Proyecto 3: Propinas** | Realización de un ejercicio para calcular propinas a partir de una cantidad inicial. |
| **Proyecto 4: Edad en años** | Desarrollo de un ejercicio para calcular la edad de una persona. |
| **Proyecto 5: Instrucciones para hacer un tinto** | Organización de los pasos necesarios para preparar un tinto de manera ordenada. |


## 3. Aprendizajes Obtenidos
Aprendí a organizar instrucciones para resolver problemas y a representar procesos mediante diagramas de flujo.


## 4. Dificultades Presentadas
Tuve que prestar atención al orden de las instrucciones y comprender cómo desarrollar cada ejercicio correctamente.


## 5. Soluciones Aplicadas
Revisé los pasos de cada ejercicio y los relacioné con sus respectivos diagramas de flujo.


## 6. Conclusiones
La sesión me permitió fortalecer mis conocimientos sobre algoritmia y comprender la importancia de organizar los pasos para resolver problemas de manera clara y ordenada.
