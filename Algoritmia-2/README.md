# Bitácora de Aprendizaje - Algoritmia

**Tema central:** Algoritmia 2. 
**Herramientas:** PSeInt.

---

## 📌 1. Objetivo de la Sesión
Aprender a organizar instrucciones lógicas para resolver problemas cotidianos y matemáticos mediante algoritmos en PSeInt, representándolos visualmente con diagramas de flujo.

---

## 🛠️ 2. Resumen de Algoritmos Desarrollados

| Archivo | Algoritmo | Descripción / Lógica Aplicada |
| `Bisiesto.psc` | **Validación de Año Bisiesto** | Determina si un año es bisiesto aplicando la condición lógica `(año MOD 4 = 0 Y año MOD 100 <> 0) O (año MOD 400 = 0)`. |
| `Parqueadero.psc` | **Cálculo de Tarifa de Parqueadero** | Evalúa el tipo de vehículo (carro/moto), la cantidad de minutos de estancia y aplica descuentos por factura de compra o límites de tarifa máxima. |
| `Semaforo.psc` | **Control de Inventario (Semáforo)** | Clasifica el stock de inventario para mostrar un estado: `agotado` (0), `pedir` (1-10) o `todo esta bien` (>10). |
| `validarEdad.psc` | **Registro con Rangos Lógicos** | Verifica que la edad ingresada sea válida ($0 \le \text{edad} \le 120$) y valida el registro si el usuario es mayor o igual a 14 años y acepta los términos. |
| `validarRegistro.psc` | **Validación Básica de Registro** | Evalúa mediante condicionales `Y` si un usuario cumple la edad mínima y la aceptación de términos para permitir el registro.
